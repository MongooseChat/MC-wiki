## Guide categories included
### How to play the game
These pages include guides on game features and aim to lower the learning curve of getting into the game and be a game feature reference.
### Modding and mod configuration
These pages include guides on how to use workshop mods and mods from other sources with your Project Zomboid game and covers subjects like how to setup the mods, load orders and mod configuration/sandbox variables, and also goes over the project zomboid local files.
### Dedicated server creation and management
These pages include guides on the process of creating a Project Zomboid dedicated server and information detailing how to setup mods on your server and also how to traverse your servers files.
### Mod creation and creating game content
These pages include guides on how to create lua mods and information about lua and kahlua used by the game while also touching on the java side of the game.
### MongooseChat systems and mod settings
These pages go over how to setup your MongooseChat instance to work best for you and your friends while also showing how to create content for MongooseChat
